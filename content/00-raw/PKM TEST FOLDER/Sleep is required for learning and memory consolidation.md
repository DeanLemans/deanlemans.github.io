# Sleep is required for learning and memory consolidation

permanent
Sleep is a must for learning because it consolidates newly formed memories after encoding. Without sufficient sleep, retention decreases because memory traces are not stabilized. This makes nap sleep a necessary condition for durable recall rather than an optional recovery phase, or at the very least, an improvement
